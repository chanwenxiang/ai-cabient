# AI开门柜项目上线执行文档

## 文档概述

- **项目名称**: AI Cabinet（AI 智能开门柜）
- **文档版本**: v1.0
- **创建日期**: 2026-07-17
- **目标**: 从本地开发环境迁移到生产上线

## 一、项目架构概览

### 1.1 技术栈

| 端 | 技术栈 | 端口/路径 |
|---|--------|----------|
| 运营管理后台 | Vue 3 + Element Plus + TypeScript + Vite | 8080/admin |
| 消费者小程序 | uni-app (微信小程序) | 独立AppID |
| 补货员小程序 | uni-app (微信小程序) | 独立AppID |
| 交易服务 (trade-service) | Spring Boot 3 + Java 17 | 8080 |
| 设备服务 (device-service) | Spring Boot 3 + Java 17 | 8081 |
| 视觉识别服务 (vision-service) | FastAPI + Python 3.10 + YOLO | 8082 |
| 消息中间件 | EMQX (MQTT) | 11883 |
| 数据库 | PostgreSQL 15 | 15433 |
| 缓存 | Redis | 6379 |
| 对象存储 | MinIO | 9000/9001 |

### 1.2 业务流程

`
消费者扫码开门 → 设备上报开门事件 → 购物会话创建
       ↓
摄像头录制视频 → 实时识别商品拿取/放回
       ↓
消费者关门 → 设备上报关门事件 → 视频上传到MinIO
       ↓
视觉识别结算 → 扣款/争议处理 → 订单生成
`
