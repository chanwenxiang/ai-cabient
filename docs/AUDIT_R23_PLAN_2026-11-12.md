## 二、失效模式镜头（每轮都复发的形状，九类 + 本批新增三类）

九类（R3–R17 沉淀）：守卫只挂 catch / 跨端单边 / 判据死代码 / `??` 改一半 / 清列缺 wrapper / foreach 缺 script / 架空修复 / 窗口截断不回显 / 状态机黑名单复活终态。

**本批新增三类**（S1–S8 落地过程实证，R23 必须带着看）：
1. **门禁判据的注释假阳/假阴**：own-source 扫描必须剥注释；字符串里的示例写法会假红（check-bare-localdate 实测）。
2. **git diff 三形态都不含未跟踪文件**：任何 diff 级对账必须并入 `ls-files --others`（S8③ 实测）。
3. **台账数字漂移**：60 处→43 处、179 表→165 表、4 处→17 处——引用规模数字前必须实跑重测（本批两次实测打脸）。
