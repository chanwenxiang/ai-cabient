===== 这份证据没有证明什么（诚实边界） =====

1. **没有人真的在浏览器里点过。** 判据全部来自 HTTP 层（curl 拉 chunk + API 调用）。
   我能证明"该 chunk 已发布且含目标串""接口可写可试发"，但**没有截图级的人工确认**。
2. **只验了 AlertRuleView 这一条路径**，没有做其他页面的回归——虽然本次构建是全量重建，
   理论上其他 chunk 内容不应变（git 只记录 hash 变化），但没有逐页比对。
3. **没有验证页面渲染后的实际交互**（例如「测试发送」按钮的 loading/错误提示样式）。
4. **`ops.alert.feishu_webhook` 仍是明文存在 dev 数据库**里；本轮未做加密或脱敏。
5. 卡死根因**只做了时序对照**（改输出目录即恢复），没有抓 OneDrive 侧的进程级证据
   （如句柄/锁），所以"OneDrive 锁"是**最一致的解释**，不是直接观测到的。
