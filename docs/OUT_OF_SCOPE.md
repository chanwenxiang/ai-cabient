# 明确不做 / 暂缓清单（out-of-scope）

> **是什么**：把「评估过但决定不做」的需求集中登记，避免它们年年挂在差距清单里以「待决策」形态复活。
> **不是什么**：不是缺陷清单（缺陷见 `docs/module-audit/ISSUES.md`），也不是排期表。
> **结论口径**：只允许四种 —— `不采纳` / `暂缓` / `有意不同` / `已采纳`。写「待定」一律不合格：
> 待定的结果就是没人定。
>
> **最后核实**：2026-11-23（来源：`docs/BUSINESS_GAP_RECHECK_2026-11-22.md` §11.4）
