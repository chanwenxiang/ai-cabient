## 三、二轮深审新发现

### R3-M01（P2）merchant 补货任务状态徽章变体缺口，色彩语义错误

`replenishment.vue:146` 用 `:class="task.status.toLowerCase()"` 动态挂状态类，但样式只定义了两个变体：

```css
.status { ... color: var(--warning, #92400e); background: color-mix(...warning 14%...) }  /* 默认=警告色 */
.status.completed { color: var(--brand-deep); background: var(--brand-soft); }            /* L2574，唯一变体 */
```

补货任务至少存在 `PENDING / IN_PROGRESS / COMPLETED / CANCELLED` 等状态（模板内 `status === 'COMPLETED'`、`selected?.status === 'COMPLETED' || checkInAt` 等判断可证）。后果：

- `CANCELLED`（已取消）落在默认样式上 → 显示**警告橙**，色彩语义错误（取消≠警告）
- `IN_PROGRESS` 与 `PENDING` 无法区分（同为默认橙）
- 徽章只有「颜色」单通道区分状态，无图标/形状差异（X03 原则未覆盖到此页）

**修复状态（同日已落地）**：已补 `.status.pending` / `.status.in_progress`（品牌青绿）/ `.status.completed` / `.status.cancelled`（石板灰）。列表默认仍过滤 `CANCELLED`，但类名语义已正确，避免再落入警告橙。

### R3-A02（P2）admin 金额列右对齐覆盖率低（col-money 24 vs 未配对 ~49）

语义列体系已建好（`main.css:557-622`：`col-text` 左 / `col-money` 右 + `tabular-nums` / `col-action` 居中），配对情况：

| class-name | 配对数 |
|-----------|-------|
| `col-text` | 256 |
| `col-action` | 59 |
| `col-money` | **24** |
| 金额类 label（元/金额/余额/毛利/营收/成本/单价/小计/抽成/手续费）**未挂** class-name | **~49**（初审宽口径 79；复验仅计 `el-table-column` 为 49） |

未配对的金额列大多靠 `align="center"` 兜底居中。数字列居中会导致多位数金额小数点不对齐，正是当初 A07 要解决的可读性问题。

**修复状态（同日已落地）**：17 个 view 共 49 列已补 `class-name="col-money"` + `label-class-name="col-money"`；`check-admin-table-align.mjs` 增加 `money-label without col-money` 统计（`STRICT_MONEY=1` 可硬失败）。复跑 unpaired=0，bare align=center 债务 632→586。

### R3-A03（P2）admin z-index 无分层约定，5 个数量级散布

| 值 | 位置 |
|----|------|
| 10000 | `main.css:23` skip-link（合理，最顶层） |
| 9999 | `BigScreenView.vue:605` 全屏大屏 |
| 5000 | `AdminLayout.vue:1159` 标签页右键菜单 |
| 4000 | `ChartBox.vue:327` 图表浮动 tip |
| 500 | `DeviceMapView.vue` ×3 地图控件 |

各值单看都有场景，但**无 `--z-*` token 分层**（dropdown/dialog/overlay/fullscreen/tip 之类），后续任何两层叠加都靠猜。EP 弹层默认 z-index 从 2000 起递增，`ChartBox(4000)` 与 `tag-context-menu(5000)` 已夹在 EP 动态区间内，存在被后弹层盖住或盖住 dialog 的隐患。

**修复状态（同日已落地）**：`main.css` 定义 `--z-sticky / --z-map-control / --z-dropdown / --z-fixed-tip / --z-context-menu / --z-fullscreen / --z-skip-link`；高位存量（skip-link、BigScreen、context-menu、ChartBox tip、地图控件、Print sticky）已改挂 token，数值不变。页面内局部叠层（0–40）仍可裸数字。

### R3-C01（P3）consumer 端字号 px 残留仅剩 video 页与导航栏

`font-size: Npx` 残留：`app-nav-bar.vue`（17px，胶囊按钮对齐微信规范，**合理豁免**）、`video.vue` 7 处（16/13/11/12px）。video 页整页深底视频场景，混用 rpx/px 但量少。merchant 端同构（video.vue 8 处 + `open-device-navigation.ts`/`text-prompt.ts` 动态注入样式，JS 注入场景可豁免）。

**修复状态（同日已落地）**：两端 `video.vue` 字号已迁 `--font-size-*` token；`app-nav-bar` 17px 加豁免注释（对齐微信胶囊）。

### R3-C02（P3）consumer 裸 rgba(255,255,255,0.x) 31 处未迁 token（上轮第 6 项余量）

分布：`index.vue`、`mine.vue`、`login.vue`、`coupons.vue`、`marketing/index.vue`、`video.vue`、`app-nav-bar.vue`。
其中 **border / box-shadow / 渐变端点** 场景（如 `border: 1rpx solid rgba(255,255,255,0.14)`、`box-shadow`）可豁免——opacity token 语义是「文字档」，硬套反而失真。**color 类**（文字色）应继续迁：`color: rgba(255,255,255,0.82)` 这类 → `var(--on-deep-opacity-78/88/92)` 就近档位。

**修复状态（同日已落地）**：`coupons` / `mine` / `index` 剩余 color 裸值已迁 token；`theme.css` 注明 border/shadow/渐变豁免。残留裸值均为 border/background 豁免场景。

### R3-X01（P3）a11y 尾量缺口（9 clickable + 2 icon）

脚本样例定位：consumer `login.vue`、merchant `disputes.vue`、`replenishment.vue`。距 95% 门槛只差 9 处 clickable，一次补齐即可把两个端都抬过线，顺便把 `MIN_ROLE_PCT` 从 70 抬到 90 做第一档收紧。

**修复状态（同日已落地）**：
- 广告图 / 申诉附图补 `role`+`aria-label`；sheet/drawer/detail 面板补 `role="dialog"`
- 两端 `empty-state` 图片图标补 `aria-hidden`（含 shared-uni 规范源）
- 抽检脚本改为接受任意 `role=`（原先只认 `button`，误报 tab/switch/checkbox）
- 默认 `MIN_ROLE_PCT` **70→90**；实跑 **392/392（100%）+ 37/37（100%）**，`MIN_ROLE_PCT=95` 亦可过
