## 四、核心业务流程分析

### 4.1 扫码开门流程
`
1. 用户扫描柜机二维码
2. 解析设备ID
3. 检查用户余额/支付授权
4. 调用开门API
5. 跳转到购物中页面
6. 等待关门结算
7. 显示结算结果
`

### 4.2 充值流程
`
1. 用户选择充值金额
2. 选择支付渠道（微信/支付宝/模拟充值）
3. 调用预下单API
4. 跳转支付页面
5. 支付回调确认
6. 余额到账
`

### 4.3 争议流程
`
1. 用户选择订单
2. 填写争议原因
3. 上传凭证图片
4. 提交争议工单
5. 等待人工审核
6. 审核结果通知
`

## 七、生产环境配置清单

### 7.1 微信小程序配置

`json
// project.config.json
{
  "appid": "wxXXXXXXXXXXXX",  // 真实AppID
  "setting": {
    "urlCheck": true  // 开启域名校验
  }
}
`

### 7.2 服务器域名配置

需在微信公众平台配置以下域名：

| 类型 | 域名 | 用途 |
|------|------|------|
| request合法域名 | api.example.com | API请求 |
| socket合法域名 | mqtt.example.com | MQTT通信 |
| uploadFile合法域名 | api.example.com | 文件上传 |
| downloadFile合法域名 | cdn.example.com | 文件下载 |

### 7.3 环境变量配置

`ash
# .env.production
VITE_API_BASE_URL=https://api.example.com
VITE_MQTT_URL=wss://mqtt.example.com:8084/mqtt
VITE_MINIO_URL=https://cdn.example.com
`

### 7.4 敏感权限申请

| 权限 | 用途 | 申请说明 |

## 八、支付对接方案

### 8.1 微信支付对接

**所需材料**:
- 微信支付商户号
- API密钥（v3）
- 商户证书
- 平台证书

**对接流程**:
`
1. 申请微信支付商户号
2. 配置支付回调域名
3. 后端配置支付参数
4. 小程序调用wx.requestPayment
5. 支付回调处理
`

### 8.2 支付宝支付对接

**所需材料**:
- 支付宝应用ID
- 应用私钥
- 支付宝公钥

**对接流程**:
`
1. 创建支付宝应用
2. 配置支付回调域名
3. 后端配置支付参数
4. H5跳转支付页面
5. 支付回调处理
`

## 九、构建与部署

### 9.1 开发环境
`ash
cd clients/consumer-mp
pnpm install
npm run dev:mp-weixin
# 用微信开发者工具打开 dist/dev/mp-weixin
`

### 9.2 生产构建
`ash
# 需要先设置环境变量
export VITE_API_BASE_URL=https://api.example.com

npm run build:mp-weixin
# 产物在 dist/build/mp-weixin
`

### 9.3 上传发布
`ash
# 微信开发者工具上传
# 或使用 miniprogram-ci
miniprogram-ci upload \
  --pp ./dist/build/mp-weixin \
  --pkp ./private.key \
  --appid wxXXXXXXXXXXXX \
  -r 1 \
  --uv 1.0.0
`
