## 功能包与数据范围

- 商家功能包（field / biz / team）在 `merchant` 表 `pack_*_enabled` 列控制，默认全开；商家管理员权限受"RBAC ∩ 功能包"双重约束（见 `MerchantFeaturePacks`）。
- 商家账号数据范围 = 绑定商户及其子组织；运营全局账号（如 13900000001）访问商家门户会被 403 拒绝。
