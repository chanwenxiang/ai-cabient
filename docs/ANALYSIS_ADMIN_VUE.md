## 七、构建与部署

### 7.1 本地开发
`ash
cd clients/admin-vue
npm install
npm run dev
# 访问 http://localhost:5173
`

### 7.2 生产构建
`ash
npm run build
# 产物在 dist/ 目录
`

### 7.3 集成到后端
`ash
# Maven 自动构建
mvn clean package -Dskip.admin.build=false

# 或手动复制
cp -r dist/* services/trade-service/src/main/resources/static/admin/
`

### 7.4 Docker部署
`ash
cd infra
docker compose -f docker-compose.full.yml build trade-service
docker compose -f docker-compose.full.yml up -d trade-service
`
