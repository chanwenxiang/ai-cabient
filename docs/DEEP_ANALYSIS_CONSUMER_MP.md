## 二、核心业务流程代码分析

### 2.1 扫码开门流程 (index.vue)

**代码结构**:
`
showLanding → 扫码按钮 → onScan() → 扫描二维码
    → startShoppingFlow() → 调用API创建会话
    → showFlowOverlay() → 显示"开门中..."
    → 成功后显示商品列表
`

**发现的问题**:

| 问题ID | 问题描述 | 代码位置 | 影响 |
|--------|----------|----------|------|
| FLOW-001 | 开门超时无明确错误提示 | index.vue:850-870 | 用户不知道发生了什么 |
| FLOW-002 | 开门失败后无重试引导 | index.vue:520 | 用户体验差 |
| FLOW-003 | 扫码二维码格式无校验 | index.vue:380 | 可能解析错误 |
| FLOW-004 | 设备离线状态检测延迟 | index.vue:290 | 用户等待时间长 |
| FLOW-005 | 开门动画与实际状态不同步 | index.vue:600-650 | 界面状态混乱 |

### 2.2 支付/充值流程 (recharge.vue + open-prep-drawer.vue)

**代码结构**:
`
选择金额 → 选择渠道 → 
    微信: onWeChatRecharge() → runWeChatRecharge() → wx.requestPayment
    支付宝: onAlipayRecharge() → openAlipayPrepay() → 跳转支付页
    Mock: onMockRecharge() → 直接到账
`

**发现的问题**:

| 问题ID | 问题描述 | 代码位置 | 影响 |
|--------|----------|----------|------|
| PAY-001 | Mock充值按钮未条件隐藏 | recharge.vue:76-80 | 测试数据泄露 |
| PAY-002 | "测试余额"文案应改为"余额" | mine.vue:10 | 用户困惑 |
| PAY-003 | 充值金额无自定义输入 | recharge.vue:28-34 | 灵活性不足 |
| PAY-004 | 支付失败无详细错误提示 | recharge.vue:190-200 | 用户不知原因 |
| PAY-005 | 待支付订单清理功能不完善 | recharge.vue:140 | 可能产生死单 |
| PAY-006 | 支付宝沙箱跳转后返回处理不完整 | recharge.ts:120-150 | 可能丢失订单 |

### 2.3 订单与争议流程 (orders.vue + result.vue + detail.vue)

**代码结构**:
`
订单列表 → 筛选条件 → 订单卡片 → 订单详情
    → 有疑问? → openDispute() → 提交争议
    → 争议列表 → 争议详情 → 等待审核
`

**发现的问题**:

| 问题ID | 问题描述 | 代码位置 | 影响 |
|--------|----------|----------|------|
| ORDER-001 | 争议提交后无进度通知 | result.vue:180-200 | 用户不知道状态 |
| ORDER-002 | 争议原因无预设选项 | result.vue:140-160 | 填写效率低 |
| ORDER-003 | 订单筛选条件不够丰富 | orders.vue:100-130 | 查找效率低 |
| ORDER-004 | 订单详情无商品图片 | order-detail.vue | 信息不完整 |
| ORDER-005 | 争议处理时间无明确提示 | detail.vue:80-90 | 用户焦虑 |

### 2.4 会员与积分流程 (member/index.vue)

**代码结构**:
`
会员中心 → 等级进度 → 积分余额
    → 积分兑换 → 兑换商品列表 → 兑换优惠券
    → 积分明细 → 收支记录
`

**发现的问题**:

| 问题ID | 问题描述 | 代码位置 | 影响 |
|--------|----------|----------|------|
| MEM-001 | 积分过期提醒缺失 | member/index.vue | 积分可能过期 |
| MEM-002 | 等级升级无动画/通知 | member/index.vue | 用户感知弱 |
| MEM-003 | 积分兑换后无使用引导 | exchange.vue | 使用率低 |
| MEM-004 | 会员权益说明不够详细 | member/index.vue | 用户不理解 |

## 八、重构建议

### 8.1 状态管理
- 使用 Pinia 或 Vuex 管理全局状态
- 用户信息、余额、购物车等状态集中管理
- 避免跨页面传递大量参数

### 8.2 组件化
- 抽取商品卡片组件
- 抽取订单卡片组件
- 抽取优惠券卡片组件
- 抽取空状态组件

### 8.3 请求层
- 统一请求拦截器
- 统一错误处理
- 添加请求缓存
- 添加请求重试

### 8.4 样式统一
- 使用统一的主题变量
- 抽取公共样式类
- 统一间距、圆角、阴影
