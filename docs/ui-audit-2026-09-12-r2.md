## 〇、总评

第一轮用户截图暴露的问题（授权弹窗按钮、遮罩、帮助中心重复标题、设备详情空洞、表格强制居中等）**大多已修掉**。  
当前剩余问题以**设计系统未收敛完**为主，其次是若干**页面级 UX 粗糙点**。按影响排序：

| 优先级 | 结论 |
|--------|------|
| 已基本达标 | 品牌主色统一、H5 手机框、字面量 `›`/`‹`、AppButton 主体、高频页 `app-status`、表格全局居中取消 |
| 仍需推进 | 硬编码色（~340 处）、字号 scale（尤其 nearby）、加载文案、登录玻璃态、帮助页单字图标、空态 `∅` |
| 本轮未验 | 运营后台运行态 UI（服务未起） |

## 二、本轮新发现 / 仍突出的问题

### 2.1 跨端设计系统

| 编号 | 严重度 | 问题 | 证据 | 建议 |
|------|--------|------|------|------|
| R2-G01 | P1 | 硬编码色仍大量存在 | consumer 约 153、admin 约 147、merchant 约 29；重灾：`index.vue`、`orders.vue`、`result.vue`、`LoginView.vue`、`AnalyticsView.vue`（图表色可单独成「数据色板」） | 业务灰/警告/浅绿先收敛；图表用 `--chart-1…n` |
| R2-G02 | P1 | typography 未完成 | `nearby.vue` L229–368 共 13× `font-size: Npx`；`verify/recharge/result/points` 仍有 64–88rpx | 一律 `--font-size-*` / `--font-size-display*` |
| R2-G03 | P2 | 双套 token 命名 | MP vs admin | 文档化映射表即可，不必强行一次性改名 |
| R2-G04 | P2 | 登录页玻璃态与扁平绿主风格冲突 | 商户登录实测 `backdrop-filter: blur(27px)` + `rgba(8,24,30,0.58)`；消费者/admin Login 亦有 `backdrop-filter` | 登录卡改为实心/半透明 token，或明确「仅登录允许玻璃态」规范 |
| R2-G05 | P2 | `.action-btn` 遗留 | 商户 `device-detail.vue` 3 处挂在 `<app-button>` 上；`result.vue` 有死 CSS | 改名为布局工具类或删除 |

### 2.2 消费者端（Playwright 实测）

| 编号 | 严重度 | 问题 | 证据 | 建议 |
|------|--------|------|------|------|
| R2-C01 | P1 | 帮助中心入口图标为单汉字圆标 | 实开 `/pages/help/help`：电、告、言、修、信、柜；源码 `help.vue` `.support-icon` | 换 SVG/iconfont（电话、公告、留言等），与 G08 对齐 |
| R2-C02 | P2 | FAQ 展开控件视觉弱 | 列表可点但展开符号不明显（旧 `+/-` 已去掉） | 使用统一 chevron 旋转动画 |
| R2-C03 | P2 | 空态默认图标 `∅` | 订单未登录页截图可见「∅」+「登录后查看订单」；`empty-state.vue` preset `icon: '∅'` | 换成简洁线框插画或品牌图形 |
| R2-C04 | P2 | 附近柜机依赖后端；失败态可用但环境 500 | 实开 nearby：`请求失败 (500)` + 重试；定位提示正常 | 环境问题；UI 上可区分「网络失败」与「无柜机」文案（若尚未区分） |
| R2-C05 | P2 | 首页落地信息密度仍偏高 | 品牌 + 标语 + 支付徽章 + 扫码 + 附近链接同屏 | 小屏再压一行垂直间距（非功能性 bug） |
| R2-C06 | P2 | 仍有直写加载文案 | `balance.vue`、`login.vue`、`index.vue`「加载商品中…」 | 统一 `UI_COPY.loading` / `loadingPrefix` |

**已确认修好（实开）：** 品牌色、帮助副标题不再重复「帮助中心」大标题、操作链接触发色 `rgb(15,118,110)`、无字面量 `›`。

### 2.3 商家端（Playwright 实测）

| 编号 | 严重度 | 问题 | 证据 | 建议 |
|------|--------|------|------|------|
| R2-M01 | P1 | 工作台信息架构重复空态 | 顶部 KPI 已全 0，下方仍叠「暂无待办事项」「暂无设备告警」两块空卡 | 有 KPI=0 时合并为一块空态，或隐藏对应区块 |
| R2-M02 | P1 | 「你好，商户测试」与「未绑定商户」并存 | 工作台截图顶栏 | 绑定态文案互斥；未绑定应引导去绑定，而不是双标签并存 |
| R2-M03 | P1 | 设备详情/经营报表状态未用 `app-status` | `device-detail.vue`、`business.vue` 仍 `{{ online ? '在线' : '离线' }}` | 复用 `.app-status` + 圆点 |
| R2-M04 | P2 | 加载文案未统一 | `home`/`replenishment`/`settlements`/`business`/`disputes`/`orders` 等「任务加载中…」「结算数据加载中…」 | `UI_COPY` |

**已确认修好（实开）：** 品牌色与 gutter、无字面量箭头。
