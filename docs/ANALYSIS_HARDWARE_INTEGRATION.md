## 三、通信协议设计

### 3.1 MQTT主题规划

#### 下行主题 (云→设备)
| 主题 | 说明 | 消息格式 |
|------|------|----------|
| cabinet/{deviceId}/command/open | 开门指令 | {"action":"open","timestamp":...} |
| cabinet/{deviceId}/command/close | 锁门指令 | {"action":"close","timestamp":...} |
| cabinet/{deviceId}/command/ota | OTA升级 | {"version":"...", "url":"..."} |
| cabinet/{deviceId}/command/config | 配置下发 | {"config":{...}} |

#### 上行主题 (设备→云)
| 主题 | 说明 | 消息格式 |
|------|------|----------|
| cabinet/{deviceId}/status/online | 上线通知 | {"status":"online","timestamp":...} |
| cabinet/{deviceId}/status/offline | 离线通知 | {"status":"offline"} |
| cabinet/{deviceId}/event/door_opened | 开门事件 | {"timestamp":..., "userId":...} |
| cabinet/{deviceId}/event/door_closed | 关门事件 | {"timestamp":..., "videoPath":...} |
| cabinet/{deviceId}/event/alert | 告警事件 | {"type":"...", "message":"..."} |
| cabinet/{deviceId}/heartbeat | 心跳 | {"timestamp":..., "status":{...}} |

#### 开门指令

## 四、核心协议对接需求

### 4.1 开门协议 (P0)

#### 流程描述
`
1. 用户扫码 → 后台验证权限
2. 后台发送开门指令 → 设备收到指令
3. 设备执行开门 → 门锁打开
4. 设备上报开门事件 → 后台创建会话
5. 摄像头开始录制
`

#### 协议参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| action | String | 是 | 固定值 "open" |
| sessionId | String | 是 | 购物会话ID |
| userId | Long | 是 | 用户ID |
| timestamp | Long | 是 | 时间戳 |
| signature | String | 是 | 签名验证 |

#### 响应要求
- 响应时间: <500ms
- 成功率: ≥99.9%
- 超时处理: 3秒无响应视为失败

### 4.2 关门协议 (P0)

#### 流程描述
`
1. 用户关门 → 门锁检测到关闭
2. 设备上报关门事件 → 后台处理会话
3. 摄像头停止录制 → 视频上传
4. 后台调用视觉识别 → 计算订单
5. 设备等待下次开门
`

#### 协议参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| eventId | String | 是 | 事件ID |
| sessionId | String | 是 | 会话ID |
| timestamp | Long | 是 | 时间戳 |
| doorStatus | String | 是 | 门状态 |
| lockStatus | String | 是 | 锁状态 |
| videoPath | String | 是 | 视频路径 |

### 4.3 门锁状态协议 (P0)

#### 状态定义
| 状态 | 说明 | 触发事件 |
|------|------|----------|
| UNLOCKED | 已解锁 | 开门指令执行 |
| LOCKED | 已锁定 | 关门检测 |
| FAULT | 故障 | 门锁异常 |
| TIMEOUT | 超时 | 开门超时未关 |

#### 告警阈值
- 开门超时: 5分钟未关门触发告警
- 门锁故障: 检测到门锁异常立即告警
- 强制开门: 检测到非法开门立即告警

### 4.4 视频录制协议 (P0)

#### 录制规则
| 场景 | 触发 | 时长 |
|------|------|------|
| 开门购物 | 开门事件 | 持续到关门后5秒 |
| 异常检测 | 异常事件 | 持续30秒 |
| 定时录制 | 定时任务 | 10秒/次 |

#### 视频参数
| 参数 | 值 | 说明 |
|------|------|------|
| 分辨率 | 1080P | 1920x1080 |
| 帧率 | 25fps | 标准 |
| 编码 | H.264 | 兼容性好 |
| 格式 | MP4 | 通用格式 |

#### 存储要求
- 本地缓存: 最小32GB
- 云端存储: 按需扩展
- 保留周期: 30天

## 七、异常处理机制

### 7.1 网络异常

| 场景 | 处理方式 | 恢复机制 |
|------|----------|----------|
| 网络断连 | 设备本地缓存事件 | 重连后同步 |
| MQTT断开 | 自动重连(指数退避) | 最大重试10次 |
| 视频上传失败 | 本地缓存+重试 | 定时重传 |

### 7.2 设备异常

| 场景 | 检测方式 | 处理方式 |
|------|----------|----------|
| 门锁故障 | 心跳上报 | 告警+禁用柜机 |
| 摄像头故障 | 心跳上报 | 告警+降级服务 |
| 存储满 | 心跳上报 | 告警+清理策略 |

### 7.3 业务异常

| 场景 | 检测方式 | 处理方式 |
|------|----------|----------|
| 开门超时 | 定时器超时 | 告警+强制关门 |
| 识别失败 | 识别超时 | 人工审核 |
| 支付失败 | 支付回调 | 订单异常 |
