## 一、选型背景与目标

### 1.1 业务目标

面向 AI 开门柜（扫码/刷脸开门 → 自由拿取 → 关门自动结算）场景，选择视觉识别合作方，需满足：

1. **识别能力可靠**：支持拿取、放回、多件、相似包装等常见购物行为；
2. **成本结构清晰**：优先买断或识别边际成本可控，避免销量上升后识别费同步滚雪球；
3. **业务可自主**：识别结果能服务自有运营与结算体系，尽量不被迫绑定对方封闭运营平台；
4. **场景可落地**：弱网环境可用、具备商用案例、支持样机/试点验证。

### 1.2 两条主流技术路线

| 路线 | 识别位置 | 费用特征 | 典型代表 |
|------|----------|----------|----------|
| 端侧识别 | 设备本地完成推理 | 硬件/授权一次投入，按单识别费可趋近于 0 | 移远 OpenVending |
| 云端识别 | 视频/图像上传云端推理 | 按次、按单或包月持续付费 | 百度智能货柜 |

## 三、移远 OpenVending：特点与优势

### 3.1 核心特点

1. **端侧推理**：识别在设备本地完成，无需每次上传整段视频到云端做算法推理；
2. **动态视觉**：针对开门选购过程做行为与商品识别，而非单张静态识图；
3. **算力平台多元**：以 SG560D 为主，并兼容多款算力平台；
4. **SKU 与上新**：宣传支持上千种商品识别；模型可在线升级；上新可缩短至数分钟量级；
5. **准确率与交叉验证**：宣传端到端识别准确率可达约 **99%**；支持单/双摄，并可结合重量等数据交叉验证；
6. **异常告警**：错拿、遮挡等异常可实时告警，支持自定义异常场景；
7. **集成支持**：官网写明可与客户应用对接，提供终端到平台的全栈支持；
8. **试用套件**：提供含开发板、摄像头、触摸屏的试用套件，便于验证。

### 3.2 主要优势

| 优势 | 说明 |
|------|------|
| 识别成本可固化 | 买断后不再按单收算法费，销量增长不再同步推高识别支出 |
| 弱网友好 | 医院、高铁、景区、地下空间等网络不稳场景更稳 |
| 结算时延低 | 本地推理，宣传秒级结算，高峰体验更好 |
| 流量成本低 | 不必每单上传大视频做云推理（订单同步仍可能有少量流量） |
| 产业链角色清晰 | 模组/方案商，习惯面向设备厂与系统集成商提供集成能力 |

### 3.3 风险与待确认点

| 风险/待确认 | 说明 |
|-------------|------|
| 无公开买断标价 | 模组、套件、算法授权须商务询价 |
| 接口细节不公开 | 识别结果如何输出、开门与结算如何协同，需 NDA/试用后确认 |
| 交付形态 | 可能需整机厂配合，或自行完成柜体改装集成 |
| 上新与运维依赖 | 上新平台、OTA、技术支持是否另收费，需合同明确 |
| 初期硬件投入较高 | 端侧算力模组会抬高单机 BOM |

### 3.4 费用模型

| 项目 | 说明 |
|------|------|
| 公开表述 | 软硬件一次性买断；无按调用次数的算法服务费 |
| 行业参照（非官价） | 同类端侧视觉套件常见约 **2,000～5,000+ 元/台**；含柜体整机更高 |
| 后续费用 | 可能仍有物联网卡流量、技术支持/维保年费（以合同为准） |
| 与云端对比粗算 | 若云端 0.12 元/单、日均 40 单，单台年识别费约 1,750 元；端侧多投入 2,000～4,000 元时，约 1～2 年可摊平 |

## 四、百度智能货柜：特点与优势

### 4.1 核心特点

1. **云端视觉识别**：摄像头采集拿取过程，云端模型识别商品与数量，作为关门结算依据；
2. **货柜场景定制**：方案明确支持反复拿取/放回、多商品一次购买等开门柜场景；
3. **商品库扩展**：支持新增商品图像采集与入库，适配品类扩充；
4. **生态成熟**：AI 开放平台、标注与训练工具链完整；有甘来等落地案例；
5. **能力分层清晰**：
   - **智能货柜方案**：面向完整开门柜识别场景（建议作为商务主谈对象）；
   - **EasyDL 零售版**：定制商品检测 API，公开计费，更偏「自助训模型 + 调接口」，**不能单独等同于完整开门柜方案**。

### 4.2 主要优势

| 优势 | 说明 |
|------|------|
| 柜机算力要求低 | 识别在云，边缘可用较低成本的采集与控制硬件 |
| 模型迭代集中 | 算法升级在云端完成，现场设备改动少 |
| 大厂品牌与商务规范 | 合同、售后、合规体系相对成熟，便于对内决策 |
| 价格部分透明 | EasyDL 零售有公开价目，便于做成本测算与试点 |
| 私有化路径存在 | EasyDL 零售可谈本地服务器部署（需商务确认） |

### 4.3 风险与待确认点

| 风险/待确认 | 说明 |
|-------------|------|
| 完整货柜方案无公开一口价 | 方案页无「每单多少钱」，须销售报价 |
| 持续识别成本 | 云端推理按次/按量计费，销量上升则费用上升 |
| 强依赖网络 | 弱网/断网时结算延迟或失败风险高于端侧 |
| 流量成本更高 | 每单上传视频或多帧图像，通信支出更大 |
| EasyDL ≠ 整套货柜 | 若只采购 EasyDL API，仍需自行补齐动态拿取判定与业务闭环 |
| 平台绑定风险 | 能否仅使用识别能力、自建运营与支付，需商务书面确认 |

### 4.4 费用模型

**（1）EasyDL 零售 · 定制商品检测（公开价目）**

| 月调用量 | 商品基本信息识别单价 |
|----------|----------------------|
| ≤15 万次 | 0.009 元/次 |
| 15 万～150 万次 | 0.008 元/次 |
| >150 万次 | 0.007 元/次 |

- 每模型约 1000 次免费额度；默认约 4 QPS；
- 一单购物可能对应多次调用，**单笔成本 = 单价 × 实际调用次数**；
- 翻拍识别另计，后付费约 0.05 元/次。

价目参考：https://cloud.baidu.com/product-price/easydl.html

**（2）智能货柜完整方案**

- 以商务报价为准（可能按单、包月、项目制或私有化打包）。

**（3）行业云端垂直方案对照（非百度独家）**

- 市场常见约 **0.10～0.15 元/单**，或约 **80～150 元/台·月** 包干，用于理解云端柜成本量级。

## 五、对照总表

| 对比项 | 移远 OpenVending | 百度智能货柜 |
|--------|------------------|--------------|
| 识别位置 | **端侧（本地）** | **云端** |
| 技术关键词 | 动态视觉 + 边缘计算 | 云端 CV 商品识别 |
| 算法是否自研 | 是（自研算法 + 自研模组） | 是（百度视觉能力） |
| 「自研」是否等于免费 | 否；成本打进硬件/授权卖断 | 否；按云服务使用量收费 |
| 识别费形态 | 买断后趋近 **0 按单费**（宣传） | **按次/按方案持续收费** |
| 弱网表现 | 强 | 较弱 |
| 单机硬件成本 | 较高（需 AI 算力模组） | 相对较低 |
| 长期单台总成本 | 销量越高越有利 | 销量越高识别费越高 |
| 公开价格 | 无标价，商务询价 | EasyDL 有标价；货柜方案商务询价 |
| 业务自主性 | 需确认识别结果与平台开放程度 | 需确认能否仅用识别、自建运营 |
| 厂商角色 | 模组 / 端侧方案商 | AI 云平台 / 方案商 |
| 更匹配的诉求 | 买断、降本、弱网、规模化铺柜 | 快速上线、低边缘算力、大厂背书 |
| 试用路径 | 试用套件 | 控制台试用 + 商务试点 |

## 六、选型建议

### 6.1 结论

| 决策倾向 | 建议主选 | 理由 |
|----------|----------|------|
| **中长期降本、买断、弱网点位多、计划规模铺柜** | **移远 OpenVending** | 端侧买断模型与「识别成本可控」目标一致 |
| **尽快验证业务、边缘硬件从简、接受按量付费** | **百度智能货柜** | 云端方案上手快，工具链与案例完整 |
| **稳健组合（推荐汇报口径）** | **短期百度试点 + 中期移远量产评估并行** | 用云端快速验证商业模式；用端侧锁定规模化成本结构 |

### 6.2 下单前必须书面确认的事项

1. 识别结果如何输出（接口形态与样例）；
2. 是否允许自有开门入口与自有支付/运营体系；
3. 完整计费清单（买断价 / 按单价 / 流量 / 年维）；
4. 断网与超时如何处理；
5. 商品上新周期与责任边界；
6. 试点数量、准确率验收标准（如抽检规则、≥约定准确率）。
