## 二、🔴 新发现：`openapi.ts` 手改生成物 + 中文损坏（建议立即修）

### R3-P1-001 — 手改 `DO NOT EDIT` 生成物，中文被毁成 `?`，CI 重生成比对将失败

| 项 | 内容 |
|---|---|
| 严重度 | **P1（CI 门禁阻断级，会让构建变红）** |
| 文件 | `packages/shared-types/src/generated/openapi.ts:11365-11368` |
| 引入提交 | `b6dba8d6` |

**现象**（实测文件内容）：

```ts
photoEvidenceUrl?: string;
/**
 * Format: int64
 * ??????????? 400??? 409????????      ← 中文全部变成半角问号
 */
expectedVersion?: number;
```

**证据链**：

1. 该文件头部自带 `AUTO-GENERATED by scripts/gen-openapi-types.mjs - DO NOT EDIT.`，且 openapi-typescript 又追加了 `Do not make direct changes to the file.`（`openapi.ts:2-8`）。
2. 本轮提交 `b6dba8d6` **只改了 `openapi.ts`**（+5/-1），**没有**改任何 spec 来源、没有跑生成器落盘痕迹。
3. CI **确实会重生成并比对**：
   - `.github/workflows/ci.yml:134` `Verify OpenAPI-generated types are up-to-date`
   - `:153` 起 jar → `:159` curl `/v3/api-docs` → `:170` `OPENAPI_CHECK_REGEN=1 OPENAPI_FILE=.tmp/live-openapi.json pnpm check:openapi-types`
   - `scripts/check-openapi-types.mjs:73-80`：重生成后执行 `git diff --exit-code -- packages/shared-types/src/generated/`，**有 diff 即 `fail('... are stale ...')` exit 1**。
4. **生成器无法复现这行注释**：
   - Javadoc 不进 spec —— `services/trade-service/pom.xml:115-117` 只有 `springdoc-openapi-starter-webmvc-ui`，**无 `springdoc-openapi-javadoc`** 模块；`springdoc-openapi-javadoc` / `maven-javadoc-plugin` 全仓 0 命中；`@Schema(` 全仓 **0 命中**。
   - 现有 spec 的实证：`.tmp/live-openapi.json` 中 `StocktakeAdjustRequest` 的 `photoEvidenceUrl` **无 description**，而其 Java 侧明明有 javadoc（`盘点照片凭证…`）→ 证明本项目 **javadoc 不会被 springdoc 采集**。
   - 因此重生成只会得到 `/** Format: int64 */`，与已提交的 `?` 注释不一致 → **diff 非空 → CI FAIL**。
5. 交叉验证：全文件 CJK 字符数 = **0**，非 `Format:` 的描述性注释**有且仅有**这一行 `?`（`openapi.ts:11367`）→ 说明这个文件此前从未承载过描述文本。

**根因**：典型的 Windows 编码陷阱 —— 用非 UTF-8（ANSI/GBK）管道或 `Set-Content` 写文件时，中文被降级为 `?`。本会话在 Bash/PowerShell 输出里也反复出现同类现象。

**修复建议（二选一，推荐 A）**：

- **A（推荐，让契约真正可读）**：
  1. 先还原生成物：`git checkout b6dba8d6~1 -- packages/shared-types/src/generated/openapi.ts`
  2. 在 Java 侧改注解（springdoc 只认注解）：
     ```java
     @Schema(description = "客户端看到的库存版本；已有库存行时必填，缺失→400，不一致→409")
     Long expectedVersion
     ```
  3. `pnpm gen:api-types` 重新生成并提交（用 UTF-8 落盘，验证无 `?`）。
- **B（仅需文档化）**：删除 `openapi.ts` 的手改注释，保留 `StocktakeAdjustRequest` javadoc + `lessons-learned` #93 即可，并把「调用方必须带 `expectedVersion`」写进独立的 **API 契约变更记录**（非生成物）。

同时建议把 `lessons-learned.md:100` 的「OpenAPI/Javadoc 标明必填」修正为「**`@Schema` 注解 + Javadoc**」——否则后来者会重复踩同一个坑。

**快速自证方法（30 秒）**：本地起 trade-service 后执行
`OPENAPI_CHECK_REGEN=1 OPENAPI_FILE=.tmp/live-openapi.json pnpm check:openapi-types`
