## 补债规则

- 「无」状态的行**只能在 R10 收口前消失**，且补的是**能失败**的用例（先注回缺陷跑一遍红，再改回绿——与 `check-competitor-benchmark` 那类 negative gate 同思路）。
- 前端文案/样式类最容易被跳过，所以 R1 起每条 P3 文案缺陷在轮报告里都要写「人工判据 = 哪个元素哪段文字」，R10 才能直接翻译成断言。
