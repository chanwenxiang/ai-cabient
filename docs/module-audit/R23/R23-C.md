  3. DTO 放行 null：`services/common/common-core/src/main/java/com/aicabinet/common/dto/UpsertSiteContractRequest.java`（仅 `siteName` 有 `@NotBlank`，`startDate/endDate` 无约束）→ 清空保存**不报错**；DB 两列可空：`V176__org_and_site_contract.sql:27-28`（`start_date DATE` / `end_date DATE` 无 NOT NULL）。
