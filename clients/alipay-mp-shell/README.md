# alipay-mp-shell — 支付宝壳小程序（芝麻先享审核载体）

> 🔴 用途：**仅作为芝麻先享·商家标准版接入的"审核载体 + 守约页容器"**。
> 官方向导明文：「小程序APPID **仅用于开通审核**」（2026-11-09 实测截图）。
> 消费者实际购物链路**不经由此小程序**：柜机二维码 → H5 落地页 → schemeUrl(appId=20000067) 唤起。

## 页面

| 页面                  | 作用                                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------ |
| `pages/orders/orders` | **订单列表占位页** —— 芝麻先享「信用服务守约链接」的承接页（官方语义：承接对客移动端"去支付"按钮跳转） |
| `pages/about/about`   | 先享后付服务说明（开通流程/守约说明/联系方式）—— 上线审核的内容支撑                                    |

## 使用步骤

1. **open.alipay.com → 企业账号 → 创建小程序**：
   - 名称：`易购智能柜`（与信用服务名称一致，≤8 字）
   - 类目：零售类目
   - 创建后把分配的 APPID 填进 `mini.project.json` 的 `app_id`
2. **支付宝小程序开发者工具**打开本目录 → 填 APPID → 真机预览确认两页正常
3. **提交审核上线**（简介：前海易购智能柜取货订单查询与守约服务）
4. 上线后回芝麻先享向导：应用选择选**此小程序** → 配置检测（配密钥/应用网关/订阅两消息）→ 信用服务配置
5. 守约链接 = 本小程序订单列表页地址（从后台/工具复制页面路径）

## 注意

- 🔴 全部文案为**支付宝/芝麻信用**口径，**严禁出现微信品牌字样**（跨平台混用会被审核驳回）
- 订单列表当前为占位态；后续真实订单接入时把 `pages/orders` 换成接口渲染（届时该小程序即"支付宝侧订单查询入口"）
